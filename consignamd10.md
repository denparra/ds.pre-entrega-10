# Pre-entrega: Modelado y Evaluación de Clasificación

## Actividad

**Pre-entrega: Modelado y Evaluación de Clasificación**

El objetivo de esta práctica es entrenar un modelo de clasificación binaria y evaluar su desempeño utilizando las métricas vistas en clase. Trabajarás con un dataset clásico para predecir si un cliente abandonará un servicio (Churn).

## Entregable

### Pasos a seguir

1. **Preparación del Entorno:** Crea un repositorio en GitHub y clona el proyecto en tu máquina local. Asegúrate de incluir un archivo `.gitignore` para Python.
2. **Análisis y Modelado:** Crea un Notebook de Jupyter (`modelado_metricas.ipynb`) donde realices la carga de datos, la división de conjuntos de entrenamiento y prueba (80/20), y entrenes un modelo de Logistic Regression o Random Forest.
3. **Evaluación de Métricas:** Calcula las siguientes métricas para tu modelo utilizando el set de prueba:
   - Accuracy
   - Precision
   - Recall
   - F1-Score
   - Matriz de Confusión
4. **Interpretación:** En una celda de Markdown dentro del mismo notebook, justifica qué métrica es la más importante para el problema de Churn (pérdida de clientes) y explica por qué basándote en los costos de los falsos negativos.
5. **Documentación:** Configura un archivo `README.md` que explique brevemente cómo ejecutar el notebook y un resumen de los resultados obtenidos.
6. **Publicación:** Sube tus cambios al repositorio y asegúrate de que sea público para su revisión.

## Qué tenés que entregar

Repositorio público en GitHub que contiene un Notebook de Jupyter con el entrenamiento del modelo, el cálculo de métricas y un archivo README descriptivo.
